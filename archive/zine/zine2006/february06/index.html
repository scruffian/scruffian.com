Jump Science. For Geeks.

I have also been thinking about rhythms/bowls. That is like a mini history of how I dig bowls. Those drawings are quite bad so let me explain:

1. At first you think you jumps in a row so you have the landing, then the flat ground, then the take off

2. Then you learn about the pump. When we discovered this we decided to make the bowl so it had no flat spots at any point. Like a bowl. Notice that this is meant to be symmetrical. This sounds good but curved landings are bad, so

3. Essentially the same but with a flatter landing and a bit less transition so its no longer symmetrical. There is also a spot with less of a transition at the bottom to give you a break inbetween jumps. This is ok but you are on flat ground so you tend to slow down between jumps, so

4. This is a bad drawing. Ignore the steepness, I have kind of exaggerated it. This is my new idea which everyone else probably already does. Basically I noticed that having the lowest point of the bowl in the middle of the jumps doesn't make much sense because you start to loose speed on the approach to the lip. This setup means you continue going downhill all the way to the lip, even if you are on flat ground. It looks like the bowl is deeper but that's just because I have drawn it badly, it doesn't have to be. The main point is i think move the lowest point nearer the lip.
