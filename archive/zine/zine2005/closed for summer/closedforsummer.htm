I have been making this website for a long as I have been riding. It used to be a lot of fun and there seemed like a lot of reasons why I wanted to do it. Slowly a lot of those reasons don't exist any more so I think its time to move on.

I have met so many people through making this website which has probably the best thing about it. Without doing the site for so long I'd never have met Joe, Poll, Yak, Aidan, Pipe, Liam, Bamber and loads of other people.

I have also learnt a lot about websites and design, which has been really useful and I think it's a direction that I would like to go into for work, so I am grateful for finding that.

Most of the people that I used to make the site with have now quit riding and moved on - apart from me and Tim. We don't really need a website to share pictures so all of those reasons are gone too.

Making a website takes a lot of time and commitment and there is not a great deal in it for you. I would rather use the time to do something else at the moment. My guitar is gathering dust. Poll said that you can make a website when it's dark and you can't dig or ride. I have a lot of other things I want to do when it is dark, which takes away time I would like to spend on the site.

So the result is that over the summer Scruffian will be running a skeleton service. I hope you don't mind. In the meantime there are some projects I will be working on, my News page is staying for now, visit Noid Clothing for more pictures, maybe I'll give Pretty Shady a long overdue overhaul, and I'll be working on some other things you may get wind of.
